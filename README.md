# DesRail
This repository is a companion to the following publications:

- "Generalised, flexible and scalable high-performance discrete-event-simulation for rail network operations"
- "Learned Deadlock Avoidance for Rail Network Simulation via Iterative No-Good Cut Generation"

Data and results are grouped by paper under `data_and_results/`:

- `data_and_results/desrail_paper/` — cpu time analysis, single run analysis, and throughput experiment
- `data_and_results/deadlock_paper/` — corridor, overlength, and Toowoomba campaigns
